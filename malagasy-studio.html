HARYFI · AUDIO-STUDIO

🎙️ Nimm deine Malagasy-Stimme auf

Mit dieser Seite kannst du direkt auf deinem Tablet deine madagassische Erklärung aufnehmen, anhören und als Audiodatei speichern. Die Aufnahme wird nicht automatisch hochgeladen.

← Zur HaryFi-Startseite

1. Deinen Text sprechen

Du kannst diesen Beispielsatz lesen oder deinen eigenen Text vorlesen.

Manao ahoana! Tongasoa eto amin’ny HaryFi. Androany isika dia hianatra teny alemà miaraka.

Verwende nur Buchstaben, Zahlen, Bindestriche oder Unterstriche. Die Datei wird als WebM-Audio gespeichert.

Bereit. Erlaube den Mikrofonzugriff, wenn dein Browser danach fragt.

2. Aufnahme in HaryFi einbauen

  1. Nimm deine Malagasy-Erklärung auf und tippe auf Aufnahme speichern.
  2. Öffne dein Repository HaryFi auf GitHub.
  3. Erstelle den Ordner audio/malagasy, falls er noch nicht existiert, und lade die Audiodatei dort hoch.
  4. Danach kann die Website die Datei über einen Audio-Wiedergabeknopf abspielen.

Hinweis: Diese Seite erstellt und speichert die Aufnahme auf deinem Gerät. Sie lädt sie nicht selbst in GitHub hoch. Für Mikrofonzugriff muss die Website über HTTPS geöffnet sein.
